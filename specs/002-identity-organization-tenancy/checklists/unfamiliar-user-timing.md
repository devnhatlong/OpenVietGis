# Unfamiliar User Timing Exercise — SC-013

**Purpose**: Validate that a person with no prior OpenVietGIS product orientation can complete the
minimum Spec 002 tenant workflow in under 5 minutes.

## Reviewer requirements

- No prior OpenVietGIS product orientation.
- No coaching from someone already familiar with the product during the measurement.
- Uses only normal in-product navigation and labels.

## Timed tasks

1. Switch to another Organization.
2. Create a Workspace.
3. Create a Project.
4. View the reviewer's own Organization membership.

## Pass condition

All four actions complete in under 5 minutes.
