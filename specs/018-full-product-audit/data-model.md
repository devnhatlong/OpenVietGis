# Audit evidence model (document records, no product schema)
- **Candidate**: Candidate.commit (immutable full Git SHA), Candidate.branch (label only), Candidate.environment (runtime/dependency versions, disposable fixture profile).
- **RequirementEvidence**: RequirementEvidence.requirement_id (stable Rxxx/FR/SC or original decision reference), RequirementEvidence.status (unverified, code_present, partial, automated_verified, manual_verified, blocked, unsupported, accepted), RequirementEvidence.artifacts (redacted paths/checksums and exact commands), RequirementEvidence.candidate (Candidate.commit). One or more records per requirement, no inherited acceptance across different candidates.
- **Gap**: Gap.id (stable Gxxx); Gap.requirement_id, Gap.severity (critical/high/medium/low), Gap.reproduction, Gap.retest, Gap.owner_scope (child spec or existing owner), Gap.status (open, verified_closed, deferred_with_decision).
- **AcceptanceDecision**: AcceptanceDecision.candidate, AcceptanceDecision.scope, AcceptanceDecision.review, AcceptanceDecision.result (pass/fail/blocked), AcceptanceDecision.manual_gate. Pass requires complete applicable evidence and zero blocking unresolved requirements.
