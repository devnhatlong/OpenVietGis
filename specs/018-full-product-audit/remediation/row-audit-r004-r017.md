## Privacy correction and remaining technical priorities

The previous frontend made HTTPS automatically enable Google Hybrid even though the shared map API and SDK support grid only. It exposed seven hard-coded unconfigured tile providers and disabled native attribution UI, with no privacy opt-in. This conflicted with the local-default/explicit-provider boundary; not a merely visual issue. Root-authorized changes limited to FE `MapWorkspace.tsx`, `engine.ts`, `maplibre-engine.ts`, `maplibre-engine.test.ts`: grid on all protocols, disabled unavailable options with visible Vietnamese privacy/approval explanation, no renderer remote raster URL construction and guarded direct requests before/after load. Current U unit/build pass; preserve earlier browser claims as earlier runtime only.
