# Evidence record contract
Each audit record must identify the roadmap group and original requirement, exact candidate SHA, observed layer (source/API/persistence/UI/independent output), command or browser scenario, fixture identity/hash, observed vs expected result, result status, timestamp, artifact reference and applicable negative cases. Manual results identify reviewer role and observation without private identifiers. A missing record, route existence, static flag, skipped test or unpinned log must never be presented as accepted. Keep no credentials, customer identifiers, production data, raw auth headers, or protected payloads. Return blocked when a safely isolated test cannot be performed.
